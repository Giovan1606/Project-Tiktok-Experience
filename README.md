# TikTok Experience

## Project Overview

TikTok Experience is a proposed innovation that extends TikTok into an experience and ticketing ecosystem, allowing users to discover personalized events and purchase tickets.

## Business Problem

- Recommendations are less personalized to individual user interests.
- Ticket and venue information may not always be well integrated.

## Proposed Solution

The solution introduces an AI Recommendation System that analyzes user search and interaction data to provide personalized and location-based event recommendations.

The system also supports the process from content discovery and searching to ticket ordering, payment, and e-ticket issuance.

## Database Design

The project includes:

- Logical ERD
- Physical Database Design
- Database Structure

The database is designed to support users, searches, content, orders, events, vendors, and ticket-related processes.

## UI/UX Design

The proposed UI/UX covers:

- User Preferences
- AI Recommendations
- Event Discovery
- Ticket Purchase
- Payment
- E-Ticket

## Project Scope

The project focuses on the process from searching and discovering content to purchasing tickets.
